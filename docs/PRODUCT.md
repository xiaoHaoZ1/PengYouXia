## 1. 定位

- 家人侠给家里长辈用；**朋友侠给年轻人用**。
- 一句话：**专门记朋友的备忘录**——记那些容易忘、想起来又用得上的小事
  （朋友孩子叫什么、他不吃什么、他想要什么、上次随了多少份子钱、谁请的饭）。
- 只给自己看。不做社交、不做分享给朋友、不做"人脉管理"。

## 2. 原则

1. **轻**：记一条备忘 = 一句话。不追求字段全，没有必填项（除了朋友名字）。
2. **快**：从打开 App 到记下一条，最多三步。
3. **不联网**：不申请 `INTERNET` 权限，不引入任何统计 / 广告 / 崩溃上报 SDK。
4. **不加 App 锁**：资料安全靠不联网 + 手机自带锁屏（与家人侠 2026-10-09 的决定一致）。
5. **只提醒生日**：其他一律不推送，不做"久未联系"之类的打扰。
6. **先自己用，后面分享给别人用**：代码与界面里不能写死任何个人信息；测试数据一律用合成名字。

## 3. 范围

### 3.1 一期（M1–M4）

| 功能 | 说明 |
|---|---|
| 朋友档案 | 名字、昵称、生日（公历 / 农历）、怎么认识的 |
| 备忘 | 五类：家人 / 喜好 / 想要 / 近况 / 其他；一条一句话 |
| 人情往来 | 钱、礼物、请吃饭；我给他 / 他给我 |
| 生日提醒 | 提前 N 天 + 当天 |
| 搜索 | 名字、昵称、拼音、备忘、往来内容都能搜 |
| 备份 | 导出一个文件、从文件恢复 |

### 3.2 明确不做

结婚纪念日等其他纪念日、礼簿（自己办事集中录入）、久未联系提醒、技能标签、
单独的借还记录（当作"其他"备忘记）、App 锁、云同步、AI 录入、iOS（Android 稳定后再说）、
自定义备忘分类（先固定五类）。

## 4. 页面

底部三个 tab：**朋友 / 人情 / 我的**。页头为与背景同色的平底，卡片白底描边无阴影。

### 4.1 朋友（首页）

从上到下：

1. 页头「朋友」，右侧「+」→ 添加朋友。
2. 搜索框（占位文字「搜名字、备忘、礼物…」）。有输入时下方整体换成搜索结果。
3. **近期生日**（30 天内，含今天；没有就整块不显示）：横向滑动小卡，每张卡
   - 名字
   - 「今天」/「明天」/「N 天后」（今天用强调色）
   - 日期：公历「3月12日」；农历「农历八月十五」
   - 知道出生年时加「满 32 岁」
4. **朋友列表**：按拼音首字母分组（A–Z，其他归 `#`），每行
   - 圆形头像：名字第一个字，主色浅底
   - 第一行：名字 + 灰色昵称
   - 第二行（灰色单行截断）：最新一条备忘内容；没有备忘则显示"怎么认识的"；都没有就不显示第二行
5. 空状态：「还没有朋友」+「添加第一位朋友」按钮。

**搜索**：匹配名字、昵称、名字全拼与首字母（如 `lw`、`laowang`）、怎么认识的、备忘内容、
往来的物品与备注。结果每行是一个朋友，第二行显示命中的那段文字（命中词高亮）。

### 4.2 添加 / 编辑朋友

- 名字（唯一必填）、昵称、怎么认识的（单行）。
- 生日：先选「公历 / 农历」，再选月、日；年可不填；农历可勾「闰月」。可清除。
- 编辑页底部「删除这位朋友」：确认框写明「将同时删除 N 条备忘、M 条往来记录，无法恢复」。

### 4.3 朋友详情

1. 页头：返回、编辑。
2. 头部：头像、名字、昵称；生日行「农历八月十五 · 还有 12 天 · 满 32 岁」；怎么认识的。
3. **备忘**：
   - 按固定顺序 家人 → 喜好 → 想要 → 近况 → 其他 分组，**没有内容的分类不显示**。
   - 每条：内容 + 灰色记录日期。点击 → 编辑 / 删除。
   - 「想要」的每条右侧有「已送出」勾选；已送出的灰显、排到该组末尾。
   - 区块底部「记一条」按钮 → 底部弹层：分类胶囊（默认选上次用的分类，首次默认「近况」）+ 输入框 + 保存。
4. **往来**：
   - 汇总一行：「我给 ¥1,600 · 他给 ¥800 · 我请 3 次 · 他请 2 次」（为 0 的项不显示）。
   - 最近 5 条 +「查看全部」；「记一笔」按钮。

### 4.4 记一笔（往来）

| 字段 | 规则 |
|---|---|
| 朋友 | 从朋友详情进入时已确定；从人情 tab 进入时先选朋友（带搜索，可直接输入新名字快速新建） |
| 方向 | 「我给他 / 他给我」；类型为请吃饭时文案变为「我请他 / 他请我」 |
| 类型 | 钱 / 礼物 / 请吃饭 |
| 金额 | 钱：必填；礼物、请吃饭：选填（「大概多少钱」） |
| 物品 | 礼物：必填（如「露营灯」）；其他类型不显示 |
| 事由 | 选填胶囊：生日 / 结婚 / 生孩子 / 乔迁 / 探病 / 过节 / 其他 |
| 日期 | 默认今天 |
| 备注 | 选填 |

**礼物 + 我给他**时，物品输入框上方列出该朋友未送出的「想要」备忘胶囊；点选后自动填物品，
保存后那条备忘自动标记为已送出（往来记录记下来源备忘）。

### 4.5 人情 tab

1. 页头「人情」，右侧「+」→ 记一笔。
2. 年份切换（默认今年，可选「全部」）+ 类型筛选胶囊（全部 / 钱 / 礼物 / 请吃饭）。
3. 汇总卡：我给出 ¥X（N 笔）· 收到 ¥Y（M 笔）；礼物 送出 a 件 / 收到 b 件；请吃饭 我请 c 次 / 他请 d 次。
4. 流水按月份分组，每行：朋友名、类型图标、描述（「随礼 ¥800 · 结婚」「露营灯 · 生日」「请吃饭」）、日期。
   「我给」用强调色（暖橙），「他给」用主色（青绿）。点击 → 编辑 / 删除。
5. 空状态：「还没有往来记录」。

### 4.6 我的

- **生日提醒**：总开关（默认开）；提前提醒「不提前 / 1 天 / 3 天 / 7 天」（默认 3 天）；提醒时间（默认 09:00）。开着时当天一定提醒。
- **数据**：导出备份、从备份恢复。
- **关于**：版本号；隐私说明「朋友侠不联网，资料只存在这台手机上。换手机前请导出备份。」
- **测试工具**（仅 debug 包可见）：填充演示数据、清空全部数据。

## 5. 数据模型（Room，库版本从 1 开始）

ID 一律 UUID 字符串；时间戳为毫秒；日期存 `epochDay`（Long）。

**`friends`**

| 列 | 说明 |
|---|---|
| `id` | PK |
| `name` | 非空 |
| `nickname` | 可空 |
| `sort_key` | 拼音排序键（名字全拼，小写），写入时生成 |
| `met_note` | 怎么认识的，可空 |
| `birthday_calendar` | `SOLAR` / `LUNAR`，可空（空 = 没填生日） |
| `birthday_year` | 可空 |
| `birthday_month` / `birthday_day` | 生日非空时必填 |
| `birthday_leap` | 是否闰月，仅农历有意义 |
| `created_at` / `updated_at` | |

**`memos`**：`id`、`friend_id`（FK，级联删除，有索引）、`category`（`FAMILY`/`LIKES`/`WANTS`/`RECENT`/`OTHER`）、
`content`、`done`（仅「想要」用：已送出）、`created_at`、`updated_at`。

**`exchanges`**：`id`、`friend_id`（FK，级联删除，有索引）、`direction`（`OUT` 我给 / `IN` 他给）、
`kind`（`MONEY`/`GIFT`/`MEAL`）、`amount_cents`（可空）、`item`（可空）、
`occasion`（`BIRTHDAY`/`WEDDING`/`BABY`/`HOUSEWARMING`/`SICK_VISIT`/`FESTIVAL`/`OTHER`，可空）、
`date_epoch_day`、`note`（可空）、`source_memo_id`（可空，FK 置空）、`created_at`、`updated_at`。

**设置**（DataStore）：生日提醒开关、提前天数、提醒时刻、上次使用的备忘分类。

约定：
- Room schema 导出到 `app/schemas/` 并入库。
- **从版本 1 起每次改表都写显式 Migration + 迁移测试，禁止 `fallbackToDestructiveMigration`**（库里是真实数据）。
- Repository 是唯一写入路径；多表写入用事务。

## 6. 生日与提醒

- 农历换算参照家人侠 `apps/android/app/src/main/java/io/github/xiaohaoz1/jiarenxia/domain/lunar/`
  （`IcuLunarCalendar`：基于系统 `android.icu.util.ChineseCalendar`，不引第三方库；`BirthdayMath`、`LunarFormat`）。
- 边界规则与家人侠 `BirthdayMath` 一致（实施时以其源码为准）：闰月出生者在无此闰月的年份按对应正常月；
  月天数不足取该月最后一天；公历 2 月 29 日的处理同家人侠。
- 年龄：知道出生年时显示「满 N 岁」= 下一次生日那年满的岁数。
- 提醒：WorkManager 每天在设定时刻检查（参照家人侠 `reminder/` 的做法：数据库是唯一事实来源，
  已过的时刻当天可补跑、按当日已通知键去重、跑完排下一次）。
- 文案：「3 天后是老王的生日（3月12日）」「明天是老王的生日（农历八月十五）」「今天是老王的生日，满 32 岁」。
  一人一条通知，点击进入该朋友详情。通知渠道「生日提醒」。
- 通知权限（API 33+）：第一次保存带生日的朋友时申请一次，被拒后不再自动弹，「我的」里显示「通知未开启」并可去开启。

## 7. 人情往来口径

- 金额汇总只算 `MONEY` 与填了金额的 `GIFT`；`MEAL` 只计次数（填了金额也不进金额合计）。
- 「我给 / 他给」分别合计，不做"差额 / 欠多少"的显示。
- 金额以分存储，界面显示「¥1,600」，有角分时显示两位小数。

## 8. 排序与搜索

- 朋友列表按 `sort_key`（拼音）排序；拼音由 `android.icu.text.Transliterator`（`Han-Latin; Latin-ASCII`）生成。
- 搜索在内存中对全部朋友做匹配即可（个人数据量小），不引入 FTS。

## 9. 备份

- 导出：全部表 + 设置 → JSON → ZIP → 可选密码加密，文件扩展名 `.pyxb`，经系统文件选择器保存。
- 加密沿用家人侠 `data/backup/BackupCrypto.kt`（PBKDF2-HMAC-SHA256 + AES/GCM）；导出时默认勾选「设置密码」，
  取消勾选时提示「不加密的备份任何人拿到都能看」。
- 恢复：先完整解析、校验，展示「N 位朋友、M 条备忘、K 条往来」，确认后**整体覆盖**（一个事务）；任何一步失败不改动现有数据。
- 备份带 `schemaVersion`，新版本必须能读旧备份。
- **系统备份与换机**（与家人侠一致）：系统云备份排除全部数据（资料不上云）；
  Android 12+ 的设备间直连迁移（换机）允许带走全部数据。Android 11 及以下的规则无法区分云备份和换机，一律排除。
  应用内导出备份仍然是唯一可靠的换机方式，「我的」页文案保持「换手机前请导出备份」。

## 11. 技术架构

- Kotlin + Jetpack Compose（Material 3）+ Hilt + Room + WorkManager + DataStore；minSdk 26、targetSdk / compileSdk 36。
- 依赖版本对齐家人侠 `D:\AIProject\JiaRenXia\apps\android\gradle\libs.versions.toml`；新增第三方依赖须在汇报中说明理由。
- 应用：`applicationId = com.pengyouxia.app`（debug 加 `.debug`），应用名「朋友侠」。
- 模块：
  - `:app` — 应用模块（Compose + Hilt），包 `com.pengyouxia.app`，内部按 `data` / `domain` / `reminder` / `ui` / `navigation` 分包。
  - `:core:model` — 纯 Kotlin/JVM 库，领域模型与纯规则，JUnit 测试，包 `com.pengyouxia.core.model`。
  - `:core:designsystem` — Android 库，主题 token 与通用组件，不依赖数据层，包 `com.pengyouxia.core.designsystem`；初始从守护侠 `core/designsystem` 复制后改造，与守护侠各自演进。
- 界面：Compose + Hilt ViewModel + StateFlow；业务规则不进 Composable。
- 正式版签名沿用家人侠密钥（见 `AGENTS.md`），文件缺失时 release 保持未签名。
